پنل مدیریت کانفیگ و سابسکریپشن — سریع، گرافیکی و کاملاً تمیز.

✅ **بدون هیچ ریمارک اجباری** روی کانفیگ‌ها و ساب‌ها

✅ رابط کاربری مدرن و گرافیکی (فارسی / انگلیسی)

✅ گروه‌های ساب (چند کانفیگ در یک لینک)
✅ ربات تلگرام اختیاری برای مدیریت و فروش
✅ محدودیت حجم، زمان، سرعت و تعداد IP برای هر کلاینت

## ⚡ اجرای سریع (لوکال)

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

سپس وارد پنل شوید: `http://localhost:8000`

نام کاربری و رمز پیش‌فرض از متغیرهای محیطی خوانده می‌شود (فایل `env.example` را ببینید).

## 🐳 اجرا با Docker

```bash
docker build -t x-ui-ali .
docker run -d -p 8000:8000 \
  -e ADMIN_USERNAME=admin \
  -e ADMIN_PASSWORD=your-strong-password \
  -v $(pwd)/data:/app/data \
  x-ui-ali
```

## ☁️ دیپلوی روی هاست‌های ابری (vibenest / Railway / ...)

۱. این ریپو را روی گیت‌هاب خودتان Push کنید.
۲. در پنل هاست (مثلاً vibenest)، ریپو را وصل کنید — `Dockerfile` به‌صورت خودکار شناسایی می‌شود.
۳. متغیرهای محیطی زیر را تنظیم کنید:

| متغیر | توضیح |
|---|---|
| `ADMIN_USERNAME` | نام کاربری ادمین |
| `ADMIN_PASSWORD` | رمز عبور ادمین (حتماً عوض کنید) |
| `SECRET_KEY` | کلید رمزنگاری نشست‌ها (اختیاری — خودکار ساخته می‌شود) |
| `PORT` | پورت سرویس (پیش‌فرض 8000) |
| `PUBLIC_BASE_URL` | آدرس عمومی پنل، مثل `https://panel.example.com` |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام (اختیاری) |
| `TELEGRAM_ADMIN_IDS` | آیدی عددی ادمین‌های ربات (اختیاری) |
| `SUPPORT_USERNAME` | آیدی پشتیبانی (اختیاری — خالی = هیچ لینکی نمایش داده نمی‌شود) |
| `SUPPORT_URL` | لینک پشتیبانی (اختیاری — خالی = هیچ هدری به ساب اضافه نمی‌شود) |

۴. یک Volume روی مسیر `/app/data` بسازید تا دیتا بعد از ری‌استارت باقی بماند.

## 📝 درباره ریمارک کانفیگ‌ها

به‌صورت پیش‌فرض، نام کانفیگ داخل اپ کاربر **فقط همان نامی است که خودتان انتخاب کرده‌اید** — هیچ متن اضافه، برند یا لینک کانالی تزریق نمی‌شود. اگر بخواهید، از تب «تنظیمات ← Subscription Template» می‌توانید نمایش حجم / آی‌دی / نام اینباند را هم به‌دلخواه فعال کنید.
